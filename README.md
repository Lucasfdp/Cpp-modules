# Cpp-modules

A series of C++ programming modules completed as part of the **42 School** curriculum. Each module introduces and builds upon core concepts of the C++ language, progressing from the basics of object-oriented programming to advanced features like templates and STL containers.

## Modules Overview

| Module | Key Concepts |
|--------|-------------|
| `cpp00` | Namespaces, classes, member functions, I/O streams |
| `cpp01` | Memory allocation, pointers to members, references, file streams |
| `cpp02` | Ad-hoc polymorphism, operator overloading, canonical class form |
| `cpp03` | Inheritance |
| `cpp04` | Subtype polymorphism, abstract classes, interfaces |
| `cpp05` | Exceptions and error handling |
| `cpp06` | C++ type casting |
| `cpp07` | Templates |
| `cpp08` | Templated containers, iterators, and algorithms |
| `cpp09` | STL containers and algorithms |

## Building

Each module contains its own `Makefile`. To compile a specific exercise:

```bash
cd cpp0X/exXX
make
```

## Requirements

- C++98 standard
- `g++` compiler with flags: `-Wall -Wextra -Werror -std=c++98`

## Part of the 42 School Curriculum

Completed as part of the core curriculum at [42 Madrid](https://www.42madrid.com/), covering the fundamentals of object-oriented programming in C++.
